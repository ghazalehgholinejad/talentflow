# TalentFlow در رزومه

این متن برای معرفی وضعیت فعلی پروژه است، نه ادعای راه‌اندازی یک محصول عملیاتی. فقط بخش‌هایی را در رزومه نگه دار که واقعاً روی آن‌ها کار کرده‌ای و می‌توانی توضیح بدهی.

## متن فارسی

**TalentFlow — نمونهٔ اولیهٔ مدیریت فرایند استخدام**  
React · TypeScript · n8n

- پیاده‌سازی نمونهٔ اولیه با رابط فارسی راست‌به‌چپ برای تعریف شغل، بررسی کاندیدا و مصاحبهٔ مرحله‌ای.
- طراحی گردش‌کارهای n8n و قرارداد ذخیره‌سازی در Data Table، همراه با کنترل وضعیت و جلوگیری از بررسی تکراری زوج شغل و کاندیدا.
- جداسازی خروجی‌های ماک از منطق فرایند و پوشش مسیرهای اصلی و خطا با تست‌های خودکار.

وضعیت: نمونه‌کار محلی با سرویس‌های بیرونی ماک؛ تأیید اجرای سرتاسری روی n8n Cloud هنوز باقی است.

## English version

**TalentFlow — Recruitment Workflow Prototype**  
React · TypeScript · n8n

- Built a Persian RTL prototype covering job creation, candidate review, and step-by-step interviews.
- Implemented n8n workflow definitions and a Data Table persistence contract with state validation and job–candidate duplicate guards.
- Separated mock provider outputs from workflow logic and added automated lifecycle and negative-path tests.

Status: local prototype with mocked external services; end-to-end cloud verification pending.
