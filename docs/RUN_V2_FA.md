# راهنمای اجرای TalentFlow v2

این نسخه برای اجرای محلی سایت و استفاده از n8n Cloud به‌عنوان بک‌اند است. هیچ نیازی به GPT، استقرار روی Sites، API مدل زبانی، Google Drive یا سرویس ایمیل ندارد. اینترنت برای ارتباط با n8n Cloud لازم است. قطع اینترنت را با «حالت محلی موفق» پنهان نمی‌کند.

## ۱. پوشه درست را باز کنید

ZIP نسخه v2 را در یک پوشه جدید Extract کنید؛ روی پوشه نسخه قبلی کپی نکنید. Terminal را باز کنید، `cd ` را بنویسید، پوشه جدید را داخل پنجره Terminal بکشید و Enter بزنید. در macOS نام پوشه دارای فاصله را داخل گیومه بگذارید.

اگر سایت قدیمی در 5173 باز است، برای نسخه جدید از 5174 استفاده کنید. باز بودن سایت قدیمی به معنی اجرای نسخه جدید نیست.

## ۲. پیش‌نیاز

Node.js نسخه 22.13 یا جدیدتر لازم است؛ نسخه LTS رسمی Node.js را نصب کنید و Terminal را دوباره باز کنید. بررسی:

```bash
node --version
npm --version
```

اگر `command not found: npm` دیدید، هنوز Node.js در همان Terminal قابل دسترس نیست. دستورهای بعدی را تا حل این مرحله اجرا نکنید.

## ۳. نصب و تنظیم اتصال

در پوشه پروژه:

```bash
npm ci
npm run setup:n8n
```

وقتی آدرس خواست، آدرس اصلی حساب را بدهید، نه لینک یک ورک‌فلو:

```text
https://your-account.app.n8n.cloud
```

تنظیم‌گر فایل `.env.local` و پوشه `n8n/local-configured` را می‌سازد. کلید مشترک تصادفی برای حفاظت از webhook ایجاد می‌شود. فایل‌های این پوشه و `.env.local` را برای دیگران ارسال نکنید. ZIP عمومی این کلید را ندارد. اجرای دوباره تنظیم‌گر، کلید فعلی را حفظ می‌کند.

## ۴. ساخت جدول در n8n

در همان حساب و همان پروژه n8n:

1. یک ورک‌فلو جدید بسازید.
2. از منوی سه‌نقطه ویرایشگر، **Import from File** را بزنید.
3. `n8n/local-configured/00_Setup.json` را انتخاب کنید.
4. Save سپس **Execute workflow** را بزنید.
5. در Data Tables باید جدول `talentflow_v2_records` با ستون‌های `key`، `kind` و `payload` دیده شود.

جدول‌های قبلی حذف یا تغییر نمی‌کنند. اجرای مجدد 00 جدول را دوباره پر نمی‌کند؛ اگر جدول هم‌نام با ستون‌های اشتباه دارید، آن را دستی حذف نکنید، ابتدا از داده‌ها نسخه پشتیبان بگیرید و وضعیت را بررسی کنید.

## ۵. فعال‌کردن API سایت

1. یک ورک‌فلو جدید دیگر بسازید.
2. `n8n/local-configured/10_Website_Gateway.json` را Import کنید.
3. Save و سپس **Publish** را بزنید؛ در نسخه‌های قدیمی‌تر، **Active**.
4. نیازی به Listen for test event نیست. آدرس سایت از `/webhook/talentflow-v2` استفاده می‌کند، نه `/webhook-test/`.

فقط 00 و 10 برای تمام مسیرهای سایت کافی‌اند. فایل 10 تمام عملیات را دارد. فایل‌های 01 تا 09 نسخه‌های مستقل همان عملیات با آدرس‌های جدا برای بازبینی و توسعه‌اند؛ 10 آن‌ها را فراخوانی نمی‌کند. می‌توانید آن‌ها را Import کنید ولی فعال‌سازی‌شان برای سایت لازم نیست. نام جدول با گزینه By Name حل می‌شود؛ اگر نسخه n8n شما از آن پشتیبانی نکرد، در دو نود Data Table، جدول `talentflow_v2_records` را از لیست انتخاب کنید.

## ۶. اجرای سایت

```bash
npm run dev -- --port 5174 --strictPort
```

نشانی چاپ‌شده در Terminal را باز کنید؛ معمولاً `http://127.0.0.1:5174`. پنجره Terminal را نبندید. در سایت «بررسی اتصال» یا «تازه‌سازی» را بزنید. فقط بعد از خواندن موفق جدول، نشان اتصال تأیید می‌شود.

توقف سایت: در همان Terminal، **Control+C**. برای روز بعد همان دستور `npm run dev -- --port 5174 --strictPort` کافی است. `npm ci` فقط بار اول یا پس از تغییر وابستگی‌ها لازم است.

فایل `RUN_TALENTFLOW.command` نیز میان‌بُر اجراست. اگر macOS آن را باز نکرد، دستورهای بالا را مستقیماً اجرا کنید؛ تنظیمات امنیتی سیستم را خاموش نکنید.

## ۷. سناریوی نمایش نمونه‌کار

1. **فرصت‌های شغلی ← ساخت شغل**: عنوان «مهندس یادگیری ماشین»، مهارت‌ها `Python, PyTorch, MLOps`، حداقل سابقه 3، هدف «استقرار مدل با معیار کیفیت مشخص». پیش‌نویس را ذخیره کنید.
2. متن را بخوانید و **تأیید و فعال‌سازی** را بزنید.
3. **بانک رزومه ← ورود ۳ رزومه نمونه**. سه فرد کاملاً ساختگی اضافه می‌شوند. تکرار این دکمه، کپی اضافه نمی‌کند.
4. هر رزومه را باز کنید و اطلاعاتش را تأیید کنید. بدون تأیید انسانی غربالگری نمی‌شود.
5. **غربالگری**: همان شغل، خروجی 2 و حداقل امتیاز 70. دو رزومه مرتبط برای این داده نمونه پیدا می‌شود. برای شغل دیگر یا داده دیگر تضمینی برای وجود دو داوطلب نیست.
6. **کاندیداها ← بررسی**: دلیل تصمیم بنویسید، سپس **تأیید و ساخت مصاحبه**. جلسه و دعوت ماک در همان رکورد ذخیره می‌شوند؛ ایمیلی ارسال نمی‌شود.
7. **مصاحبه‌ها ← باز کردن مصاحبه**. لینک برای هر جلسه جدا و تا ۷ روز معتبر است. لینک localhost برای نمایش روی همین رایانه است، نه ارسال به فردی در اینترنت.
8. برای هر سؤال، پاسخ را تایپ کنید یا **قرار دادن پاسخ نمونه ماک** بزنید، سپس **ثبت پاسخ در n8n**. نمونه، رونوشت صدای شما نیست.
9. بعد از ثبت ۵ پاسخ، **پایان مصاحبه و دریافت نمره ماک**. گزارش و عدد نمره دیده می‌شود.
10. به داشبورد برگردید و تازه‌سازی کنید. در **گزارش و تصمیم نهایی** نمره، شواهد متن پاسخ، تاریخچه و کنترل تأیید/رد انسانی را نشان دهید.
11. صفحه را Reload کنید و همان گزارش را دوباره باز کنید. برای اثبات ذخیره واقعی، در Data Tables رکورد `kind=application` را باز کنید؛ `payload` شامل پاسخ‌ها و گزارش است.
12. گزارش JSON را از سایت دانلود کنید. این گزارش می‌تواند شامل اطلاعات داوطلب و لینک جلسه باشد؛ تنها برای نمایش مجاز نگه دارید.

## عیب‌یابی

| مشکل | اقدام |
|---|---|
| 404 برای talentflow-v2 | فایل جدید 10 را در حساب درست Import و Publish کنید؛ تست سبز کافی نیست. |
| خطای جدول | 00 را در همان پروژه n8n اجرا کنید و جدول انتخاب‌شده در نودها را بررسی کنید. |
| Unauthorized یا خطای اجرای نود اول | `.env.local` و فایل 10 باید خروجی همان اجرای setup باشند. فایل 10 از `release-v2` کلید ندارد و عمداً اجرا نمی‌شود؛ از `local-configured` وارد کنید. |
| Timeout | شاید ثبت انجام شده باشد؛ اول تازه‌سازی و Execution را بررسی کنید. عملیات را کورکورانه تکرار نکنید. |
| غربالگری صفر نفر | شغل فعال؟ رزومه تأییدشده؟ مهارت‌های منطبق؟ قبلاً برای همان شغل پرونده ساخته نشده؟ حدنصاب مناسب؟ |
| میکروفن کار نمی‌کند | پاسخ متنی مستقل از میکروفن کار می‌کند. مجوز میکروفن اختیاری است. |
| صدای فارسی پخش نمی‌شود | به صداهای نصب‌شده مرورگر/سیستم وابسته است؛ متن سؤال را بخوانید. |
| Port already in use | نسخه قدیمی را با Control+C متوقف کنید یا از پورت دیگر استفاده کنید. |
| صفحه هنوز ظاهر قدیمی دارد | آدرس 5174 و مسیر پوشه Terminal را بررسی کنید؛ نسخه Desktop قدیمی را باز نکرده باشید. |

## مرز ماک و واقعی

واقعی: HTTP سایت↔n8n، بررسی کلید، Data Table، شناسه‌ها، وضعیت‌ها، جلوگیری از تکرار، ثبت پاسخ، گزارش، تاریخچه و تصمیم مسئول استخدام.

ماک: تولید شرح شغل، خروجی ورودی Drive، سؤال‌های الگو‌محور، امتیاز رزومه بر اساس تطبیق مهارت، امتیاز مصاحبه بر اساس طول پاسخ، متن نمونه STT، ارسال ایمیل. این نمرات ارزیابی معتبر استخدامی نیستند.

صوت: ضبط و بازپخش محلی تا دو دقیقه؛ بایت‌های صوتی ذخیره نمی‌شوند. TTS با صدای مرورگر است، نه API. ورودی رزومه TXT است؛ PDF/OCR متصل نیست.

جایگزینی سرویس‌ها با API واقعی تنها با قرار دادن کلید انجام نمی‌شود: قرارداد خروجی، نود ارائه‌دهنده، اعتبارسنجی، خطاها و آزمون‌ها هم باید پیاده شوند. `N8N_MODE=live` عمداً خطا می‌دهد تا خروجی ماک پنهانی به‌عنوان AI واقعی اجرا نشود. راهنمای توسعه در `docs/ARCHITECTURE_V2.md` است.

این نسخه نمونه‌کاری تک‌کاربره است، نه سامانه استخدام عمومی. جدول‌ها تراکنش چندرکوردی و قفل توزیع‌شده ندارند. تنها یک نمونه سرور سایت اجرا کنید؛ از فراخوانی همزمان مستقیم endpointهای مستقل خودداری کنید. برای استفاده واقعی به ورود کاربران، سطح دسترسی، حفاظت از داده، نگهداری صوت، صف/قفل و آزمون مقیاس نیاز است.

مستندات رسمی: [Webhook و Publish در n8n](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.webhook/) و [عملیات Data Table](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.datatable/).
